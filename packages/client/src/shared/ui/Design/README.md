# Общие компоненты оформления

Импорт: `~/shared/ui` или `~/shared/ui/Design`.

`DesignTheme` задаёт область оформления: `appearance="dark"` для лендинга и авторизации; `appearance="inherit"` учитывает выбранную пользователем тему. Глобальная настройка темы не изменяется.

Палитра, градиент кнопок и радиусы определены в `tokens.css`. `Design.module.css` содержит оформление компонентов и локальные семантические переменные (`--design-bg`, `--design-panel`, `--design-fg`, `--design-muted`, `--design-border`). CSS экранов отвечает за композицию и адаптивную раскладку.

| Компонент | Назначение |
| --- | --- |
| `Brand` | Логотип и название приложения |
| `ActionButton` | Основная, контурная, приглушённая или прозрачная кнопка; поддерживает `asChild`, `loading`, `disabled` |
| `Surface`, `FormSurface` | Панель и панель с оформлением полей формы |
| `PanelHeading` | Заголовок панели с необязательным действием |
| `IconTile`, `StatusBadge` | Акцентная иконка и метка состояния |
| `MetricCard` | Подпись, значение показателя и иконка |
| `TimerDial` | Круговой индикатор с названием, временем и подписью; `progress` от 0 до 100 |
| `SessionControls` | Старт/пауза и завершение; состояние передаёт вызывающий компонент |
| `ActivityRow` | Выбор занятия и отдельная область действий без вложенных кнопок |
| `BarChart` | Столбчатый график с доступным текстовым описанием значений |
| `NavigationItem` | Ссылка навигации с активным состоянием |
| `LanguageSelect` | Выбор языка; обработчик изменения задаётся снаружи |
| `OrbitDecoration` | Декоративные орбиты |
| `DesignEmptyState` | Сообщение пустого состояния или ошибки |

Компоненты не обращаются к API и не хранят доменное состояние. `AppPreview` передаёт демонстрационные данные; `HomeDashboard` получает план, аналитику и состояние сессии через существующие запросы и мутации. Время дневного показателя включает текущий активный сегмент; недельные группы используют UTC и обозначены в интерфейсе.
